# Linktree Pessoal

Este repositório contém um projeto simples de **Linktree** que eu desenvolvi para centralizar e facilitar o acesso aos meus principais links e redes sociais. A ideia foi criar uma página leve, direta e funcional, onde qualquer pessoa pode encontrar rapidamente meus canais de contato e conteúdos online.

## Sobre o Projeto

Criei essa Linktree com **HTML** e **CSS**, sem o uso de frameworks ou bibliotecas externas. Optei por um design limpo e organizado, mantendo uma identidade visual coerente com o meu estilo pessoal.

Foi um projeto simples e tranquilo de desenvolver. Não encontrei grandes dificuldades durante a criação, o que me permitiu focar nos detalhes visuais e na boa usabilidade, especialmente em dispositivos móveis.

## Tecnologias Utilizadas

- **HTML5**: para estruturar todo o conteúdo da página
- **CSS3**: para a estilização, organização dos botões e responsividade

## Funcionalidades

- Links de redirecionamento para as minhas redes sociais (Instagram, LinkedIn e git hub)
- Layout centralizado e responsivo
- Estilo visual personalizado com cores e tipografia pensadas para manter uma apresentação agradável
